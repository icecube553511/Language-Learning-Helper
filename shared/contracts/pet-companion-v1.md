# 冰子宠物交互契约 v1

`pet-companion-v1` 定义 LexiTrack 的跨端陪伴宠物语义。冰子是只存在于
presentation 的瞬态 UI 状态，不写入词库、学习进度、设置或任何持久化文件。

## 身份与资源

- 名称：`冰子`
- 原始源图：`shared/assets/branding/pet_image.png`
- 运行资源：`shared/assets/pets/bingzi.png`
- 运行资源是由 `tools/prepare_pet_asset.py` 从原始源图生成的透明 PNG，平台
  只能加载运行资源，不应让 domain/application 读取图片文件。

## 目标区域

presentation 可将当前页面的几何区域注册为以下类型：

- `control`：按钮、选项框、搜索栏、导航项等可点击控件
- `surface`：卡片、面板和边框
- `chart`：图表边界和曲线
- `edge`：窗口或屏幕的四条边

注册区域使用屏幕坐标、稳定 id 和 `[x, y, width, height]` 矩形边界。
宠物尺寸参数表示从中心到边界的半尺寸。可见的按钮、输入框、选项框、
滑块、数字输入框、列表、滚动条和导航项必须各自注册为 `control`；禁用但
仍可见的控件仍可作为停留边界。不可见、尺寸为零、被滚动/祖先容器裁剪或
位于当前页面之外的区域不得作为目标。普通文字标签不要求单独注册。

应用自有的 Dialog、Popup 和 Toplevel 使用各自独立的坐标系、目标注册表与
宠物 overlay，其中的可见控件和边框遵循相同注册规则。同一时刻只显示一只
冰子：最上层应用窗口激活时隐藏下层 overlay，关闭后恢复上一层。系统文件
选择器、系统消息框、通知栏等由平台进程托管且应用无法覆盖的 UI 不属于本
契约目标范围。

矩形目标按扩展半尺寸后的边界距离选择，chart 按折线路径距离选择；同距离时
按注册顺序稳定决策。切页后的导航项和窗口边缘仍可参与最近目标选择，但
`fall` 优先选择当前位置下方可落到的区域。

## 行为

在没有用户拖动时，冰子以约 `50 ms` 的 tick 频率自动行动：

1. 可以在控件/面板边框上水平或垂直滚动，并在 `chart` 的记忆曲线上滑行；
2. 可以在屏幕边缘或任意注册区域上短暂停留；
3. 目标不在同一条边界上时，沿竖直方向飞行到最近目标；
4. 页面导航发生时，先从当前位置掉落到新页面最近的可交互区域，再恢复
   自动行动；
5. 用户按下冰子并拖动时立即进入 `dragging`；presentation 保留按下点相对
   宠物中心的抓取偏移，宠物中心随指针位移并限制在窗口内，不得在按下时
   瞬移到指针中心；
6. 用户释放指针后保留当时经过窗口约束的宠物中心位置，并从该处选择下一个
   最近目标。

实现可以使用不同的 easing 或姿态，但不得改变上述状态转换、命中范围和
拖放语义。宠物本身的命中区域应稳定，不因标签或动画帧改变尺寸。
